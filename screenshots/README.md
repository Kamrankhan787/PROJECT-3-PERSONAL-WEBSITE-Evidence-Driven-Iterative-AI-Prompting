# Website Screenshots & Responsive Validation

This directory stores visual verification captures and responsive viewport validations for Kamran Khan's personal portfolio.

## Viewports Verified
1. **Desktop Ultra-Wide & Standard (1440px / 1280px):**
   * Full multi-column grids, interactive cards, floating quick badges, sticky glassmorphic navbar.
2. **Laptop / Notebook (1024px):**
   * Balanced column spacing, responsive game preview card, flexible prompt evolution timeline.
3. **Tablet (768px):**
   * Smooth 2-column to 1-column adaptation, responsive card stacking, touch-friendly CTA buttons.
4. **Mobile (480px & 375px):**
   * Sliding mobile navigation drawer, fluid typography, full-width touch targets, zero horizontal overflow.

## Visual Design Highlights
* **Palette:** Sleek dark mode (`#0a0f1d`, `#0f172a`, `#1e293b`) with vibrant cyan (`#38bdf8`), purple (`#a855f7`), and amber accents.
* **Typography:** Clean Inter / system-ui hierarchy with clear contrast and high readability.
* **Interactive Elements:**
  * Prompt Evolution 4-stage interactive comparison switch.
  * Certificate Lightbox / Fullscreen Modal preview.
  * Live Web Game card with direct netlify link and animated game canvas simulation.
  * Responsive Mobile Navigation Menu.
